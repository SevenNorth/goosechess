# 阶段 4 人机模拟报告

## 1. 验证范围

验证日期：2026-07-28。

无界面模拟通过正式的 `LocalAuthority`、`LocalGameController`、公开 `GameDecisionView` 和 `AiTurnController` 推进。模拟器不直接调用 reducer，不读取规则 RNG 游标，也不使用 `Math.random()`。本地座位在无界面验证中同样由 AI 策略驱动，以覆盖完整对局；浏览器实际游玩时该座位仍由用户提交相同的命令类型。

异常门禁包括：无合法命令、authority 拒绝命令、超过最大轮数、超过命令上限以及未产生胜者。任一异常都会使模拟命令以非零状态退出。

## 2. 运行命令

```powershell
npm run simulate -- --mode 1v1 --games 1000 --seed-start 1
npm run simulate -- --mode 1v2 --games 1000 --seed-start 10001
npm run simulate -- --mode 1v3 --games 1000 --seed-start 20001
```

当前 npm 版本会提示未知 CLI config 警告，但参数仍会作为位置参数传入模拟器；这与本机已有的 `sass-binary-site` npm 配置警告一样，不影响结果。

## 3. 汇总结果

| `1v3` | 20001 至 21000 | 1000 / 1000 | 100% | 8.140 | 0 |

胜者分布：

| 模式 | 本地座位 | AI 1 | AI 2 | AI 3 |
| --- | ---: | ---: | ---: | ---: |
| `1v1` | 551 | 449 | - | - |

事件频率已由模拟器按事件 ID 完整输出。三组中触发最多的是 `crab`、`tailwind`、`shortcut` 和 `cook`；所有 15 个默认事件均至少在一个模式中被触发。胜率目前包含座次、碰撞目标采用下一座位及 AI 策略偏好的共同影响，只作为回归基线，不作为平衡性结论。

## 4. 模拟发现

首次模拟发现领域事件 schema 要求 `token-moved.path` 非空，但棋子在起点受到后退效果时，规则会合法地产生空路径。协议现已允许领域事件使用空路径；表现层仍只在路径非空时生成路线和跳跃 cue。该边界已有回归测试。

阶段 4 的退出条件已满足。阶段 5 可以在不改变规则写入路径的前提下，将同一 authority 的快照和表现 cue 接入 PixiJS/XState 核心样片。
