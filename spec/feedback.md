## 第一次反馈

- [x] 选定模式后缺少返回首页的功能
  - 已修复：对局顶部栏增加“返回首页”按钮，通过客户端路由返回模式选择页；准备阶段也可使用。
- [x] 屏幕能放下完整棋盘时，棋子运动不应移动视角
  - 已修复：完整棋盘能以 1:1 比例显示时固定镜头，移动动画不改变缩放与焦点。
- [x] 屏幕不能放下完整棋盘时，需要移动视角，且允许玩家拖拽棋盘自由查看
  - 已修复：裁切视口启用自动镜头跟随和鼠标拖拽，并限制镜头不越出棋盘边界。
- [x] 每个玩家最多同时持有一个道具卡；再次获得道具卡时，由玩家选择保留哪一个
  - 已确认：规则状态始终只保存一个 `itemId`；再次获得道具时进入新旧二选一界面，可保留当前道具或替换为新道具。

  ![初始棋盘](../example_screenshots/Snipaste_2026-07-29_12-26-30.png)

- [x] 棋盘上的红色格子意义不明
  - 已修复：事件格统一显示高对比度 `!`，并在棋盘中加入“事件格”图例。
- [x] 20→21 的连线与其他格子重叠
  - 已修复：调整第 21 格位置，使 20→21 连线避开第 56 格及相邻路线。
- [x] 事件应直接占据路线格子，而不是放在路线侧边
  - 已修复：事件标记直接替代对应路线格的普通编号，不再作为侧边装饰。
- [x] 终点房子应直接位于路线上，并包裹三个格子

- [x] 棋子移动时没有和格子对齐
  - 已修复：单个棋子独占格子时严格居中；只有多个棋子同格时才按座位顺序错位显示。

## 第二次反馈

- [x] 使用道具时改为居中弹窗确认
  - 已修复：道具详情从底部抽屉调整为棋盘中央的确认弹窗；主动道具需要点击“确认使用”后才提交。
- [x] 选择保留道具时使用居中弹窗，并高亮选中的道具
  - 已修复：新旧道具先通过单选卡片选择，选中项使用高对比边框和勾选标记；点击“确认保留”后才提交选择。

## 第三次反馈

- [x] 停留在同一格的时候， 直接交换位置，不允许一个格子有两个棋子。比如棋子A,B，棋子A先出发，从第0格到了第3格；棋子B后出发，从第0格到了第3格， 这个时候，第三个应该只有棋子B， 棋子A回到第0格。动画流程是，在棋子B动画完成之后，占据了格子，棋子A被碰撞，飞回棋子B的这次行动的触发点
  - 已修复：普通碰撞按“移动棋子先落地，再将原占位棋子飞回本次移动起点”的顺序播放；碰撞护盾生效时改为原占位棋子留在原格、移动棋子弹回起点，避免普通路线格出现两个棋子。
