# 阶段 6 完整 65 格对局报告

## 1. 实现范围

验证日期：2026-07-28。

Web 客户端已从 16 格样片切换为默认奥普港地图。地图包含 0 至 65 共 66 个固定逻辑坐标，路线沿外圈进入内圈；九个地标保持既定顺序和相对位置。第 63、64、65 格同时绑定喧声屋地标并属于 `winningSpaceIds`，任何普通移动或事件移动最终落入其中之一都会锁定胜者。

`BoardScene` 不再导入样片地图，而是在创建时接收 `MapDefinition`。格子、路线、地标坐标、地标资源和胜利区域都来自地图数据；16 格定义继续保留为非默认地图样例，用于维持不同格数和地图切换的扩展边界。

## 2. 表现与流程

- 66 个格子、九个地标、路线和棋子使用固定 `1280 x 820` 逻辑坐标等比缩放。
- 四款纯外观棋子具有 idle、active、hop 和 hit 表现；皮肤不影响规则或 AI。
- 普通移动和事件移动复用路线预览、目标圈、路线淡出和逐格跳跃。
- 折返包含终点停顿和转身；碰撞支持击退、护盾格挡，交换位置使用独立 relocation cue。
- 地标事件层、骰子检定结果和道具替换严格串行显示，避免操作层互相遮挡。
- HUD 显示暂停状态和全局骰子上限；额外行动保持当前行动者并写入对局日志。
- 获胜后先播放棋盘压暗与 63–65 格高亮，再显示喧声屋横向终局舞台和动态名次。
- `AudioPort` 继续只接收 cue，没有声音文件或播放依赖。

阶段实现期间浏览器完整对局发现并修复两项 UI 竞态：AI effect 清理后未释放输入锁；事件结果与道具替换层同时出现并争抢指针事件。
